# 📚 DIDAXIE

O **DIDAXIE** é um sistema desenvolvido para auxiliar professores na **organização, criação e gerenciamento de aulas**, permitindo que o conteúdo seja preparado manualmente ou com o auxílio de **Inteligência Artificial**.

O projeto também pretende oferecer recursos para **correção de atividades**, acompanhamento dos alunos e visualização de **gráficos de desempenho**, facilitando a análise da evolução das turmas.

> 🚧 **Projeto em desenvolvimento**
> Atualmente, a interface front-end está sendo desenvolvida. As funcionalidades de back-end, Inteligência Artificial e demais integrações serão implementadas posteriormente.

---

## 🎯 Objetivo

O DIDAXIE tem como objetivo centralizar ferramentas úteis para professores em uma única plataforma, tornando mais simples tarefas como:

* Planejamento e organização de aulas;
* Criação de conteúdos e atividades;
* Geração de materiais com auxílio de Inteligência Artificial;
* Correção de atividades;
* Acompanhamento do desempenho dos alunos;
* Visualização de dados através de gráficos.

---

## 🛠️ Tecnologias

O projeto utiliza:

* **HTML5** — estrutura das páginas;
* **CSS3** — estilização e responsividade;
* **JavaScript** — interatividade no front-end;
* **Java** — desenvolvimento da lógica e back-end da aplicação.
